# Number Converter

A simple Java console-based application that converts numbers between different number systems. The program provides an interactive menu that allows users to select a conversion type and view the results.

## Features

* **Decimal Converter** – Converts decimal numbers into binary, octal, and hexadecimal.
* **Binary Converter** – Converts binary numbers into decimal, octal, and hexadecimal.
* **Octal Converter** – Converts octal numbers into decimal, binary, and hexadecimal.
* **Hexadecimal Converter** – Converts hexadecimal numbers into decimal, binary, and octal.
* **Roman Numeral Converter** – Converts decimal numbers to Roman numerals and Roman numerals to decimal numbers.
* Input validation to handle invalid entries.
* Interactive menu with options to continue or exit.

## Technologies Used

* Java
* Java Scanner
* IntelliJ IDEA

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Locate `NumberConverter.java`.
4. Run the `main()` method.
5. Select a conversion option from the menu and enter a number.
